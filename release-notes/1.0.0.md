# Nexi Android SDK 1.0.0 🎉

We are excited to release version 1.0.0 of the Nexi Android SDK.

The SDK enables native Kotlin applications to communicate with Nexi EP2 on the same Android terminal or on a reachable terminal in the local network. It handles terminal communication internally, allowing integrators to initiate payments and terminal operations without generating protocol messages or running an additional service.

## Capabilities

Version 1.0.0 supports:

- Payments, refunds, and reversals
- Terminal activation and deactivation
- Terminal information and status requests
- Abort, initialization, configuration, transmission, close-day, reset, and receipt reprint operations
- Typed Kotlin requests and results
- A simplified `NexiResult` with `status`, typed `error`, detailed `errorCode`, and `correlationId`
- Consolidated financial data in `TransactionResult`, including amount, currency, tip, payment method, masked card number, authorization reference, approval code, transaction date, acquirer identifier, receipts, and DCC details
- Separate merchant and authorization references, with referenced refunds accepting the original payment's `authReference`
- Merchant and customer receipt handling
- Dynamic Currency Conversion result details
- Structured error and cancellation handling
- Automatic return to the merchant application
- Optional redacted diagnostic logging

Raw terminal XML and low-level operational fields are not exposed through transaction results. Sanitized communication remains available in the SDK's private diagnostic logs.

The SDK defaults to localhost for on-terminal integrations and accepts a `terminalHost` for supported network-terminal integrations. It does not require Docker, an HTTP proxy, or a separate background service.
