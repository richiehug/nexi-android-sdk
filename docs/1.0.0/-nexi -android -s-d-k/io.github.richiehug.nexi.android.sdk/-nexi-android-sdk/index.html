NexiAndroidSdk

class NexiAndroidSdk

Brings Nexi payments into an Android merchant application.

The SDK connects the application to Nexi EP2 and provides typed financial operations, terminal administration, receipts, DCC results, recovery, lifecycle handling, and an optional transaction overlay. Create one instance with create and retain it for the lifetime of the integration.

All terminal-facing methods are suspending and return operational outcomes as NexiResult. Regular operations are serialized. abort is the only out-of-band operation and applies only while a payment or refund is active.

Operations

The primary transaction operations are presented first:

  • Payment, including optional pending-receipt recovery

  • Refund

  • Reversal

  • Abort
